# **App Name**: ChartFlow AI

## Core Features:

- Dataset Upload: Dataset Upload: Allow users to upload datasets in common formats (CSV, JSON).
- AI Chart Generation: AI Chart Generation: Accept natural language queries via the Gemini API and generate corresponding charts. The LLM will act as a tool and make its own judgements as to the ideal information to surface in order to make it work best.
- Visualization Suggestions: Visualization Suggestions: Offer AI-suggested visualizations based on the uploaded data.
- Chart Display: Chart Display: Display generated charts in an interactive and customizable format.
- Chart Export: Chart Export: Enable users to export charts in various formats (PNG, JPG, PDF, SVG).
- Chart Configuration: Interactive Chart Configuration: Allow users to customize various chart elements (titles, labels, axes).
- Layout Saving: Dashboard Layout: Save custom layouts to 'dashboard' format.

## Style Guidelines:

- Background color: Dark charcoal (#222222) to provide a sleek, modern backdrop.
- Primary color: Electric Blue (#7DF9FF) for key interactive elements, signaling cutting-edge functionality.
- Accent color: Fuchsia (#FF77FF) for highlights and call-to-action elements, providing vibrancy.
- Body and headline font: 'Inter' (sans-serif) for a clean and modern user experience.
- Use minimalistic icons in white or electric blue to maintain a clean and modern aesthetic.
- Employ a modern, card-based layout with ample spacing to ensure readability and a clean interface.
- Use subtle animations and transitions to enhance user interaction and provide visual feedback without being distracting.
